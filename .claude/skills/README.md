# Skills

Claude Code skills for this repo: how ninsei should look, read and play.

| Skill | Use it for |
|---|---|
| `fake-app-craft` | Building or redesigning any screen so it looks like real period software |
| `ninsei-ux-review` | Reviewing screens from screenshots: craft, faithfulness, pillars, usability |
| `ninsei-game-design` | Shaping and critiquing mechanics, progression and content |
| `human-interface-guidelines-1992` | Mac-style screens (Liza, the Sense/Net stack, alerts) |
| `tui-design` | Text-mode and terminal screens (btop chrome, NinShell, AnarchyOS, BBSes, the suite) |
| `ux-heuristics` | General usability: Nielsen's heuristics, Krug, severity ratings |

The first three are ours. The last three are copied unchanged from community repos; refresh them by copying again, not by editing:

| Skill | Source | Licence |
|---|---|---|
| `human-interface-guidelines-1992` | [diskd-ai/ui-guidelines](https://github.com/diskd-ai/ui-guidelines) | MIT (per its README) |
| `tui-design` | [hyperb1iss/hyperskills](https://github.com/hyperb1iss/hyperskills) `skills/tui-design` | MIT |
| `ux-heuristics` | [wondelai/skills](https://github.com/wondelai/skills) `plugins/ux-design/skills/ux-heuristics` | MIT |
