# Skills

Claude Code skills for this repo: how ninsei should look, read and play.

| Skill | Use it for |
|---|---|
| `fake-app-craft` | Building or redesigning any screen so it looks like real period software |
| `ninsei-ux-review` | Reviewing screens from screenshots: craft, faithfulness, pillars, usability |
| `ninsei-game-design` | Shaping and critiquing mechanics, progression and content |

Three third-party guides live under `fake-app-craft/references/`. They are reference material the two UI skills point at, not skills of their own, so they never trigger by themselves (their descriptions are broad enough to fire on any TUI or form question). They are copied unchanged; refresh them by copying again, not by editing:

| Guide | Use it for | Source | Licence |
|---|---|---|---|
| `human-interface-guidelines-1992` | Mac-style screens (Liza, the Sense/Net stack, alerts) | [diskd-ai/ui-guidelines](https://github.com/diskd-ai/ui-guidelines) | MIT (per its README) |
| `tui-design` | Text-mode and terminal screens (btop chrome, NinShell, AnarchyOS, BBSes, the suite) | [hyperb1iss/hyperskills](https://github.com/hyperb1iss/hyperskills) `skills/tui-design` | MIT |
| `ux-heuristics` | General usability: Nielsen's heuristics, Krug, severity ratings | [wondelai/skills](https://github.com/wondelai/skills) `plugins/ux-design/skills/ux-heuristics` | MIT |
